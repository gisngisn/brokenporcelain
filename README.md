# Broken Porcelain

A dark minimalist digital museum experience.

## About

Broken Porcelain is a virtual gallery dedicated to fragile memories,
porcelain aesthetics and emotional visual storytelling.

The project focuses on:

- Dark gothic atmosphere
- Museum-style presentation
- Cinematic artwork display
- Minimal interface design

## Features

- Full-screen artwork exhibition
- Original image ratio preservation
- Spotlight lighting effect
- Artwork title and description display
- Smooth cinematic transitions
- Responsive layout
